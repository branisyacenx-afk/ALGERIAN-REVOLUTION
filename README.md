# ثورة الجزائر | The Algerian Revolution

مشروع لعبة تاريخية ثلاثية الأبعاد تستكشف مقاومة الاستعمار الفرنسي من 1830 إلى الاستقلال سنة 1962.

> **الحالة:** تأسيس نموذج أولي قابل للتشغيل على الويب. هذا المستودع لا يدّعي أنه إصدار نهائي أو لعبة AAA مكتملة.

## تشغيل النسخة الأولية

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح الرابط المحلي الذي يعرضه Vite.

## التحكم
- **W / A / S / D:** الحركة.
- **Shift:** الركض.
- **Space:** القفز.
- **زر الفأرة الأيسر:** التصويب/إطلاق النار.
- **Esc:** تحرير مؤشر الفأرة.
- على الهاتف: استخدم عصا الحركة الافتراضية وأزرار الحركة الظاهرة.

## أوامر الجودة
```bash
npm run check
npm run build
```

## نطاق النسخة الحالية
نموذج تقني أولي يستخدم Three.js وأشكالاً هندسية مؤقتة لاختبار الحركة والكاميرا والتصويب والهدف. الشخصيات والبيئات النهائية والأصوات والرسوم التاريخية عالية الجودة ستحتاج إلى إنتاج أصول فنية ومراجعة تاريخية مستقلة.
