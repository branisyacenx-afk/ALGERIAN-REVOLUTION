# ثورة الجزائر | The Algerian Revolution

مشروع لعبة تاريخية ثلاثية الأبعاد تستكشف مقاومة الاستعمار الفرنسي من 1830 إلى الاستقلال سنة 1962.

> **الحالة:** تأسيس نموذج أولي قابل للتشغيل على الويب. هذا المستودع لا يدّعي أنه إصدار نهائي أو لعبة AAA مكتملة.

## تشغيل النسخة الأولية

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح الرابط المحلي الذي يعرضه Vite.

## التحكم
- **W / A / S / D:** الحركة.
- **Shift:** الركض.
- **Space:** القفز.
- **E:** جمع صندوق الإمدادات قربه.
- **R:** إعادة تلقيم السلاح.
- **زر الفأرة الأيسر:** التصويب/إطلاق النار.
- **Esc:** إيقاف اللعبة مؤقتاً/إظهار شاشة الاستراحة.
- على الهاتف: استخدم عصا الحركة الافتراضية، اسحب على مساحة اللعب لتدوير الكاميرا، واستعمل الأزرار الظاهرة.

## أوامر الجودة
```bash
npm run check
npm run build
```

## الأنظمة المضافة في آخر تحديث
- خريطة مصغرة تعرض اللاعب والخصوم والإمدادات ونقطة التجمع.
- دوريات حراسة تتحول إلى مطاردة عند اقتراب اللاعب.
- مهلة قصيرة بين ضربات الخصوم مع مؤشر بصري لتلقي الضرر.
- شاشة إيقاف مؤقت ومتابعة وإعادة المهمة.
- نظام إصابة للخصوم يتطلب أكثر من إصابة قبل إخراجهم من المواجهة.
- شاشة إتمام مستقلة تعرض ملخص أهداف المهمة وزر إعادة اللعب.
- ركض سريع يستهلك التحمّل ويتجدد عند التوقف.

## نطاق النسخة الحالية
نموذج تقني أولي يستخدم Three.js وأشكالاً هندسية مؤقتة لاختبار الحركة والكاميرا والتصويب والهدف. الشخصيات والبيئات النهائية والأصوات والرسوم التاريخية عالية الجودة ستحتاج إلى إنتاج أصول فنية ومراجعة تاريخية مستقلة.

## المهمة التجريبية الأولى
1. ابدأ المهمة من شاشة البداية.
2. اتبع المسار الترابي وابحث عن صندوق الإمدادات.
3. اقترب منه واضغط **E** (أو اضغط رسالة التفاعل على الهاتف) لجمعه.
4. اتبع العلامة الذهبية حتى نقطة التجمع لإكمال المهمة.
