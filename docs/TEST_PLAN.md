# خطة الاختبار اليدوي — النموذج الأولي

> هذه قائمة تحقق للاختبار على متصفح حقيقي. نجاح GitHub Actions يثبت فحص TypeScript وبناء Vite فقط، ولا يثبت أن كل جهاز أو متصفح يعمل بلا عيوب.

## الحاسوب
- [ ] فتح التطبيق دون أخطاء في وحدة التحكم.
- [ ] بدء المهمة وإخفاء شاشة البداية.
- [ ] W يتقدم نحو المسار والهدف، وS يرجع، وA/D يتحركان جانبياً.
- [ ] Shift يزيد سرعة الحركة، وSpace يقفز ويعود اللاعب إلى الأرض.
- [ ] سحب الفأرة يدوّر الكاميرا، وEsc يحرر المؤشر.
- [ ] علامة التصويب تتوافق مع اتجاه الإصابة.
- [ ] R يعيد تلقيم المخزن من الذخيرة الاحتياطية.
- [ ] E لا يجمع الصندوق إلا عند الاقتراب منه.
- [ ] جمع الصندوق يزيد الذخيرة الاحتياطية ويحدّث تقدم المهمة إلى 50%.
- [ ] الوصول إلى نقطة التجمع قبل جمع الصندوق لا ينهي المهمة.
- [ ] الوصول بعد جمع الصندوق ينهي المهمة ويحدّث التقدم إلى 100%.
- [ ] عند انتهاء الصحة تظهر إعادة المحاولة وتعيد اللاعب والأعداء والموارد.

## الهاتف
- [ ] واجهة الأزرار لا تتداخل مع شاشة البداية أو معلومات المهمة.
- [ ] عصا الحركة تتحكم في الاتجاهين وتعود إلى المركز بعد رفع الإصبع.
- [ ] السحب على مساحة اللعب يدوّر الكاميرا دون تمرير الصفحة.
- [ ] أزرار القفز والإطلاق والتلقيم تعمل دون نقر مزدوج.
- [ ] زر التفاعل يظهر قرب صندوق الإمدادات ويمكن الضغط عليه.
- [ ] الأداء مقبول على جهاز متوسط ومنخفض، ولا توجد سخونة أو هبوط إطارات شديد.

## بوابة القبول
لا يُعلن النموذج جاهزاً للاختبار العام إلا بعد إكمال القائمة على متصفحات وأجهزة فعلية وتسجيل العيوب وإصلاح الحرجة منها.
